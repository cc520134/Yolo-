# YOLO 标注工具

基于 PyQt5 的 YOLO 目标检测标注软件。

## 功能
- 打开图片文件夹，侧边栏列出所有图片
- 鼠标左键拖动画矩形框（颜色随当前类别），右键删除框
- 类别管理（添加 / 删除 / 保存 classes.txt）
- 保存标注需先选择保存目录，标注 .txt 与 classes.txt 写入保存目录
- 自动加载 / 保存每张图片同名 .txt 标注
- 滚轮缩放，F 适应窗口
- 切换图片自动保存上一张
- **AI 自动标注**：加载 YOLOv8 (.pt) 模型，批量推理全部图片并写入标注

## AI 自动标注
- 工具栏【自动标注】按钮 → 选择 `.pt` 模型 → 输入置信度阈值 → 批量推理
- 框架：ultralytics YOLOv8，模型格式 `.pt`（也支持 `.onnx`）
- 已有标注的图片默认**跳过**（不覆盖）
- 模型类别名自动合并进项目 classes.txt（已存在的复用，不存在的追加）
- 进度对话框可随时取消
- 结果存储：YOLO `.txt`（与手动标注一致），写入保存目录
- 加载失败（如 torch/ultralytics 异常）会弹窗提示，不崩溃

## 输出格式
每张图片生成同名 `.txt`，每行一个标注：
```
class_id x_center y_center width height
```
坐标均归一化到 [0,1]。类别名保存在目录下 `classes.txt`，每行一个类别（行号即 class_id）。

## 安装
```
pip install -r requirements.txt
```

## 运行
```
python main.py
```

## 快捷键
| 键 | 功能 |
|----|------|
| A / ← | 上一张 |
| D / → | 下一张 |
| S | 保存当前 |
| Del | 删除选中框 |
| F | 适应窗口 |
| 1-9 | 选择类别 |
| 右键 | 删除所指框 |
| Ctrl+O | 打开目录 |
| Ctrl+S | 保存 |
